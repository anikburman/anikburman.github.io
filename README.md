# anikburman.github.io

Personal academic website of Anik Burman, PhD candidate in Biostatistics, Johns Hopkins Bloomberg School of Public Health.

## Files
- `index.html` — the website (self-contained)
- `Anik_Burman_CV.pdf` — CV linked from the CV tab
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Publish on GitHub Pages
1. Create a public repository named `anikburman.github.io`.
2. Upload all files in this folder to the repository root (Add file → Upload files → Commit).
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` → Save.
4. Site is live at https://anikburman.github.io within a few minutes.

## Updating
- New CV: replace `Anik_Burman_CV.pdf` with a file of the same name.
- Content changes: regenerate `index.html` and re-upload it.
